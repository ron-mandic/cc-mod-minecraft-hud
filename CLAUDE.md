# cc-mod-minecraft-hud: notes for agents

ron-mandic's private Claude Code marketplace `cc-mod-minecraft-hud` (`.claude-plugin/marketplace.json`, registered as a local directory source). It holds one mod, `plugins/minecraft-hud`. The git remote is the **private** GitHub repo `ron-mandic/cc-mod-minecraft-hud`. The naming scheme is one repo per mod, `cc-mod-<mod>`, with the marketplace named like the repo. The user guide is `README.md` (German). ron-mandic works in German, mostly in the Claude desktop app (Code tab).

## Never publish

minecraft-hud draws Mojang's original Minecraft sprites and font. They may not be redistributed.

- Keep the GitHub repo private. Do not add this folder to a public marketplace or upload the assets anywhere.
- Never install straight from GitHub: a clone has no assets. Clone, run `fetch_assets.py`, then add the local folder as the marketplace.
- `.gitignore` keeps out `plugins/minecraft-hud/assets/`, the generated `hooks/sprites.ts` and `docs/*.png` (the previews show sprites).
- `plugins/minecraft-hud/tools/fetch_assets.py` rebuilds all of them locally from Mojang's official `client.jar`, SHA-1 checked.

## Install state

Installed user-wide since 2026-10-05: `minecraft-hud@cc-mod-minecraft-hud`, `enabledPlugins` in `~/.claude/settings.json`. The marketplace is declared in `extraKnownMarketplaces` as `{ "source": "directory", "path": "$HOME/projects/cc-mod-minecraft-hud" }`.

The install is a copy pinned to `version`, at `~/.claude/plugins/cache/cc-mod-minecraft-hud/minecraft-hud/<version>/`; it is not loaded in place. To ship a change:

1. Bump `version` in `plugins/minecraft-hud/.claude-plugin/plugin.json`.
2. Run `claude plugin update minecraft-hud@cc-mod-minecraft-hud`.
3. Restart, or run `/reload-plugins`.

0.2.1 is current.

## What the mod shows

The band above the prompt, as the vanilla Java HUD without the hotbar:

| HUD element | Shows |
| :- | :- |
| hearts | 7-day limit, all models |
| armour | Fable weekly limit |
| hunger | 5-hour session limit |
| air bubbles | another model-scoped weekly limit, Sonnet first, only while used |
| XP bar + level | context window % |

Icons show what is left, rounded up like health. Text columns show what is used.

## Data

- **Free figures.** 5 h, 7 d and context come from `$.session.usage()` and `session.measure`, the response headers.
- **Fable (and Sonnet)** come from the undocumented `GET https://api.anthropic.com/api/oauth/usage`, header `anthropic-beta: oauth-2025-04-20`. It is called through `$.session.authorize()` and `$.http.fetch`, so the token never reaches the mod. Live answer on 2026-10-05: `five_hour, seven_day, extra_usage, limits[session, weekly_all, weekly_scoped:Fable], spend, member_dashboard_available`. `/hud debug` prints the fields seen.
- **Fetch cadence.** One shared cache, `$.store` key `plan`, for all sessions. A fetch runs after a main-thread turn once the cache is 2 min old (1 min after a Fable turn), and when idle every `refresh_minutes` (5). Back-off: 429 → 10 min, 401/403 → 30 min.
- **Prefs.** Plugin options (`userConfig`) are the defaults. `$.store` `prefs` (global, set with `/hud …`) beats them. `$.store` `repos[gitRoot]` (`/hud an|aus`) beats both. Each install has its own store.

## Rendering, and what was learned the hard way

- **Desktop band.** A `Box` row with `justifyContent="space-between"` and `flexWrap="wrap"`: the HUD image first, then one image per column (Sitzung, Woche, Fable, Sonnet, Kontext).
- **Pixel geometry.** Columns have 3 text lines on the HUD rows (y 0/10/20), height 28. Columns reserve their widest form, so the band does not shift.
- **Scale.** `auto`: 2 if everything fits, tolerating only the `LARGE_ENOUGH` first give-ups; else 1.5. The art is never scaled by a non-step factor.
- **Plain `Svg` only.** `isInteractive` puts the SVG in a frame with an opaque white background, so there are no tooltips. Plain images are transparent on both themes.
- **Text** is drawn in the Minecraft bitmap font with the game's shadow (colour >> 2, offset 1,1). ron-mandic wants plain words, no icon strings: `Reset 16:30`, `Reset Mi 00:00`, `98k von 200k`. The hooks environment has the local timezone (Europe/Berlin).
- **`CELL_PX = 7.8`** turns `bodyColumns` into CSS px. It is an estimate: `/hud debug` shows the real cell count; adjust if columns drop too early or wrap.
- **Validator rule.** Every function that receives `$` must be a top-level function in `register.tsx`, because the validator traces `$`. Helpers in other files stay pure.
- **Engine rules.** No `$.state.set` while rendering. Promises nobody awaits go through `background()`.
- **Tests.** Every `$` call beneath the plugin needs an answer, `on('noun.method', () => ({ value }))`, including `session.start` and `ui.render`. `$.session.authorize` works only once the plugin's scan allows it.

## Workflow

```bash
claude plugin validate plugins/minecraft-hud
claude plugin test plugins/minecraft-hud
bun plugins/minecraft-hud/tools/preview.ts --docs
```

Type-check: use the tsconfig from the header of the `claude-code.d.ts` the plugin-authoring skill writes (strict, `noUncheckedIndexedAccess`), including that file, `hooks/` and `types/`. Mods require Claude Code 2.1.287+. Use the desktop app's binary, `~/Library/Application Support/Claude/claude-code/<version>/…/claude.app/Contents/MacOS/claude`. Run tests with `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.

**Hot reload.** Load the `plugin-authoring` skill, copy the mod into `~/.claude/dev-mods/<session-id>/minecraft-hud`, and let ron-mandic enable hot reload. Edit there, then rsync back here (excluding `README.md`, `.claude-plugin/types`, `tsconfig.json`). A forked or resumed session gets a new dev-mods folder and does not load the old one; dev-mods copies are disposable once their session ends.

**Avoid a double band.** The installed copy loads in every session, so a hot-reloaded dev copy would draw a second band and register `/hud` twice. Develop in a session opened in this folder, and switch the installed copy off for this folder only:

```bash
claude plugin disable minecraft-hud@cc-mod-minecraft-hud --scope local
```

This writes `.claude/settings.local.json` here. Afterwards, re-enable it with `enable … --scope local`.

Without hot reload: edit here, bump `version`, run `claude plugin update minecraft-hud@cc-mod-minecraft-hud`, then `/reload-plugins`.

When removing anything, move it to `~/.Trash` and never delete it outright. Retired copies from 2026-10-05 went there; this folder and the private GitHub repo are the only copies kept.
